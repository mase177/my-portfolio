# Portfolio Nguyễn Minh Trí - Development Guide

Welcome to the personalized portfolio of Nguyễn Minh Trí, a GIS Intern & Researcher. This project has been migrated from a legacy structure to a modern, minimalist "Furniture Design" inspired aesthetic.

## Tech Stack

- **Backend:** Flask
- **Frontend:** HTML5, Tailwind CSS (CDN), Font Awesome
- **Data:** JSON-driven project gallery
- **Assets:** Managed in `frontend/static/images` and `frontend/static/docs`

## Development Workflows

### 1. Updating Projects
Modify `data/projects.json` to add or edit research entries. Images should be placed in `frontend/static/images/`.

### 2. Updating Personal Bio
Edit `frontend/templates/index.html` directly for major bio changes or social link updates.

### 3. CV Management
Replace `frontend/static/docs/cv.pdf` with the latest version of your CV to keep the "View CV" button up to date.
